# HITs-Map-Proj / University Map

University Map — командное Android-приложение на Kotlin и Jetpack Compose с интерактивной картой университетской территории.

Приложение помогает ориентироваться на территории университета, находить интересующие точки и строить маршруты. Кроме обычного пользовательского режима, в проекте есть режим разработчика для работы с картой и демонстрации различных алгоритмов.

## Возможности

В приложении реализованы:

* интерактивная карта университетской территории;
* определение текущего положения пользователя;
* построение маршрутов между точками;
* отображение заведений общественного питания;
* отображение достопримечательностей и других точек интереса;
* подбор места для обеда;
* построение маршрута по нескольким выбранным точкам;
* кластеризация объектов на карте;
* пользовательский и разработческий режимы;
* визуализация работы некоторых алгоритмов.

## Построение маршрутов

Для поиска пути между точками используется алгоритм **A***.

Карта представлена в виде сетки с проходимыми и непроходимыми клетками. Алгоритм учитывает препятствия и строит маршрут от начальной до конечной точки.

В режиме разработчика предусмотрена пошаговая визуализация работы A*: можно увидеть открытые и просмотренные клетки, текущую позицию алгоритма и итоговый маршрут.

Также приложение преобразует реальные географические координаты пользователя в координаты внутренней сетки карты.

## Маршрут по достопримечательностям

Пользователь может выбрать несколько интересующих его точек.

Для определения порядка их посещения используется **муравьиный алгоритм**, а маршруты между отдельными точками строятся с помощью A*.

Таким образом приложение пытается подобрать более удобную последовательность посещения выбранных мест.

## Маршрут по местам питания

В приложении можно задать блюда или категории еды, которые пользователь хочет найти.

Для подбора маршрута между подходящими заведениями используется **генетический алгоритм**.

При построении маршрута учитываются:

* необходимые блюда;
* расположение заведений;
* длина маршрута;
* текущее положение пользователя;
* часы работы заведений;
* предполагаемое время передвижения.

Отдельные части маршрута между точками также рассчитываются с помощью A*.

## Рекомендация места для обеда

В проекте реализовано дерево решений, которое может рекомендовать подходящее место для обеда.

При выборе учитываются различные параметры пользователя, например:

* текущее местоположение;
* бюджет;
* количество свободного времени;
* готовность ждать в очереди;
* погода;
* готовность пройти определённое расстояние;
* предпочтения по еде и напиткам.

На основе этих параметров дерево решений выбирает подходящее заведение.

## Кластеризация

В приложении также реализован алгоритм **K-Means**.

Пользователь или разработчик может выбрать точки на карте и разделить их на заданное количество кластеров. Алгоритм рассчитывает центры кластеров и распределяет выбранные точки между ними.

## Режимы приложения

При запуске можно выбрать один из двух режимов.

### Пользователь

Режим предназначен для обычной работы с картой и доступными функциями приложения.

### Разработчик

Режим позволяет подробнее работать с внутренними механизмами приложения и алгоритмами, в том числе:

* запускать и визуализировать A*;
* выбирать точки для кластеризации;
* работать с маршрутами;
* изменять некоторые элементы карты;
* просматривать и тестировать алгоритмические функции.

## Техническая часть

Интерфейс приложения реализован с помощью **Jetpack Compose** и Material 3.

Для получения местоположения используется Google Play Services Location.

Вычислительно затратные операции, такие как построение и оптимизация маршрутов или кластеризация, выполняются с использованием Kotlin Coroutines.

Некоторые основные файлы проекта:

* `MainActivity.kt` — запуск приложения и выбор режима;
* `MainScreen.kt` — основной экран и взаимодействие с картой;
* `SelectionScreen.kt` — выбор пользовательского или разработческого режима;
* `Pathfinding.kt` — поиск пути с помощью A*;
* `AntColonyOptimizer.kt` — муравьиный алгоритм;
* `GeneticFoodRouteOptimizer.kt` — оптимизация маршрута по местам питания;
* `Clustering.kt` — K-Means;
* `DecisionTreeClassifier.kt` — реализация дерева решений;
* `LunchTraining.kt` — подготовка данных для рекомендации места для обеда;
* `Models.kt` — основные модели данных.

## Запуск

Для запуска проекта потребуется Android Studio.

1. Склонировать репозиторий:

```bash
git clone https://github.com/AvaNarIn/UniversityMapProj.git
```

2. Открыть проект в Android Studio.

3. Дождаться синхронизации Gradle.

4. Запустить приложение на Android-эмуляторе или физическом устройстве.

Минимальная версия Android SDK — **28**.
